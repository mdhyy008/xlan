# xlan 使用说明

把文件发到同一个 WiFi 下的另一台电脑，不用 U 盘，不用微信传。

---

## 一分钟上手

两台电脑连同一个 WiFi，**各自先开一个窗口跑服务**（这个窗口别关）：

```
xlan serve
```

看到 `xlan 服务已启动` 就说明起来了。然后另开一个窗口：

**发的那台**，敲：

```
xlan send 报告.pdf --to 小王的电脑
```

**收的那台**，第一次会等你点头，敲：

```
xlan inbox accept
```

只有一条待接收时，这条命令直接就收了。文件会出现在「下载」文件夹里的 `xlan` 里。

---

## 怎么打开窗口

**Windows**：按 `Win + R`，输入 `cmd`，回车。出来一个黑窗口，就在这里敲命令。

> 更方便的办法：打开放 `xlan.exe` 的那个文件夹，点一下上面的地址栏，输入 `cmd` 回车。这样窗口直接就在这个文件夹里，不用来回切换路径。

**macOS**：启动台里搜「终端」，打开。

**Linux**：桌面右键，或者 `Ctrl + Alt + T`。

---

## 两边都要有 xlan

Windows 用 `xlan.exe`。**不用双击**——双击只会闪一下个说明。正确用法是在窗口里敲 `xlan`，服务会自动在后台起来。

想省事，把 `xlan.exe` 放进一个固定的文件夹，以后都在那个文件夹里开窗口。

---

## 先启动服务

每台电脑都要先跑一个：

```
xlan serve
```

它会一直占着这个窗口，并且打印：

```
--------------- xlan 服务已启动 ---------------
  版本   0.1.0
  设备   牛牛 (34071bf000673de9)
  接口   http://0.0.0.0:43003
  收件   /sdcard/Download/xlan
--------------------------------------------
按 Ctrl-C 停止。另开一个终端用 xlan scan / send / text。
```

**这个窗口要一直开着**，关掉就等于下线了。要敲别的命令，另开一个窗口。

不想每次收东西都点确认，可以开自动接收：

```
xlan serve --auto-accept
```

这个模式下**同一个网络里任何人发的文件都会直接收下**，不问你了。公用的 WiFi 上别开。

不想一直占着窗口，就让它跑到后台去：

```
xlan serve -d
```

之后用 `xlan status` 看它在不在，用 `xlan stop` 停掉。

如果忘了开服务就敲 `xlan scan`，会直接告诉你「服务没有在运行，另开一个终端敲 xlan serve」。

## 让它开机自己跑（可选）

不想每次手动开服务：

```
xlan autostart on
```

- Windows：写进注册表的启动项，登录后自动在后台跑
- Linux：装成 systemd 用户服务
- macOS：装成 LaunchAgent

查看状态 `xlan autostart status`，取消 `xlan autostart off`。

## 让 xlan 变成全局命令（可选）

如果每次都要先 `cd` 到程序目录才能用，执行一次：

```
xlan path on
```

之后重开一个命令行窗口，在任何目录都能直接敲 `xlan`。取消用 `xlan path off`。

## 看看谁在线

```
xlan scan
```

会列出同一网络里开着 xlan 的电脑，像这样：

```
名称                 平台         地址             id
小王的电脑           windows      192.168.1.7      a1b2c3d4e5f60718
```

**最左边那个名字，就是发文件时要写的名字。**

扫不到人？看最后面的「出问题了」。

---

## 发文件

```
xlan send 报告.pdf --to 小王的电脑
```

文件名里有空格，两边加引号：

```
xlan send "季度报告 终稿.pdf" --to 小王的电脑
```

发完会显示：

```
已发送给 小王的电脑
```

**这句话出来，才是真的传到对方电脑上了。** 中途关窗口会断。

---

## 传大文件想快一点

默认一块一块地传。可以让它同时传好几块：

```
xlan config set threads 4
```

数字越大越快，最多 8，默认 4。改完立刻生效，不用重启。

主要对几百 MB 的大文件有用；几十 KB 的小文件快不了多少。

不想占满整条网（比如还要同时开视频会议），可以限速：

```
xlan send 大文件.iso --to 小王的电脑 --limit 5M
```

## 一次发多个

```
xlan send 报告.pdf 数据.zip 照片/ --to 小王的电脑
```

挨个发，每个都会显示自己的进度。

## 重复的文件不会重传

如果对方已经有一模一样的文件（内容完全相同），会直接告诉你：

```
小王的电脑 已经有同一个文件了，没再传。
```

同名但内容不一样，会存成 `报告 (1).pdf`，不会覆盖。

## 断点续传

传大目录时对方断线了，重新发一次同样的目录：

```
发送 照片  35.0%  340 MB / 972 MB
续传：跳过 12 个已经传完的文件
```

已经传完的文件不会重传，只补剩下的。

## 发整个文件夹

一模一样：

```
xlan send 照片 --to 小王的电脑
```

对方的 `照片` 文件夹里，目录结构会原样保留，空文件夹也会留着。

---

## 发一段文字

发给所有人：

```
xlan text "会议改到下午三点"
```

只发给某个人：

```
xlan text "你那份表我看过了" --to 小王的电脑
```

文字是**广播**出去的，不需要对方先确认。对方开着 xlan 就能收到。

---

## 收东西

### 最省心的做法：先把对方加成信任

```
xlan trust add 小王的电脑
```

加完这一次，以后这个人发来的东西**自动收下**，两边都不用再操作。

### 第一次收（默认行为）

对方还没被你信任时，东西会先挂起，等你说行不行。敲：

```
xlan inbox
```

看到这样的记录：

```
11-04 00:06 [文件] 小王的电脑: 报告.pdf (2048 字节) pending
```

`pending` 就是「等你确认」。直接敲：

```
xlan inbox accept
```

只有一条待接收时会自动选中。

如果列表里有好几条待接收的，就加上前面的序号：

```
xlan inbox accept 2
```

想一次全收下：

```
xlan inbox accept --all
```

不想要，把 `accept` 换成 `reject` 就行。

传了一半对方断了、一直显示 `active` 不动了，用这个清掉：

```
xlan inbox cancel
```

想一次清掉所有没收完的：

```
xlan inbox cancel --all
```

不用管也行——**5 分钟没有新数据会自动标记失败**。

### 人不在电脑前

没关系，待确认的记录会一直留着，等你什么时候回来处理。

但**发的那台电脑得一直等着**——它最多等 60 秒，超时就退出了。对方这时候再点接受，东西也传不过来了，得让对方重新发一次。

所以最省心的做法是：**先把对方加成信任**，以后就不用两边配合了。

---

## 暂停和继续

发大文件的时候想临时让一下带宽，按 **Ctrl-Z** 暂停，再按一次继续：

```
已暂停，再按一次 Ctrl-Z 继续
继续传输
```

在别的窗口操作也行。发送开始时会给一个任务号：

```
传输 id sc8024ffe（Ctrl-Z 暂停，或 xlan pause sc8024ffe）
```

```
xlan sends              看看有哪些在发
xlan pause sc8024ffe    暂停
xlan resume sc8024ffe   继续
```

注意：暂停是**发送方**的操作。接收方只能取消，不能暂停。

## 查看收发记录

```
xlan log
```

```
2026-11-04 01:44  发送  小王的电脑  报告.pdf (2.1 MB) done
2026-11-04 01:40  接收  小李的电脑  照片 (1.4 GB) done  2m10s
```

清理旧记录：

```
xlan log clean --older-than 30d
```

## 清理收件箱

收件箱会一直攒着。清理 30 天前的记录：

```
xlan inbox clean --older-than 30d
```

连文件一起删（**会真的删掉收件目录里的文件**）：

```
xlan inbox clean --older-than 30d --with-files
```

先看看会删多少（不动手）：

```
xlan inbox clean --older-than 30d --dry-run
```

## 文件收到哪了

| 系统 | 位置 |
|---|---|
| Windows | `下载\xlan` |
| macOS | `下载/xlan` |
| Linux | `下载/xlan` |
| 安卓手机 | 文件管理器里的 `Download/xlan` |

文件名撞了不会覆盖，会自动变成 `报告 (1).pdf`、`报告 (2).pdf`。

想换地方：

```
xlan config set recv_dir D:\收件
```

## 出问题了

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| `xlan scan` 一个人都扫不到 | 不在同一个 WiFi；或者公司/学校网络把设备隔开了 | 确认连着同一个 WiFi。还不行，用 `xlan scan --deep`（慢一点，约 4 秒）再试 |
| 扫不到，但对方能看到你 | 对方防火墙拦了 | Windows 第一次运行时弹的防火墙窗口，要选「允许访问」 |
| 显示「已发送」，对方没反应 | 对方在等你确认 | 让对方敲 `xlan inbox` |
| 一直停在「等待确认」然后超时 | 对方没在电脑前 | 让对方先 `xlan trust add 你的名字`，再重发 |
| 传一半不动了，显示 active | 对方断线了 | 等 5 分钟自动变 failed，或 `xlan inbox cancel` |
| 手机收不到 | 手机连的是移动网络不是 WiFi | 手机和电脑要连同一个 WiFi |
| 发文字显示「0 人回执」 | 没人收到你的广播 | 这不代表发失败。可能是网络挡了广播，先跑 `xlan doctor` 看看 |

还是不行，敲这个，把结果发给我：

```
xlan doctor
```

---

## 几个要知道的

- **只在同一个 WiFi 下能用。** 不在一个网络，两台电脑谁也看不见谁。
- **传输默认是加密的**，同一个 WiFi 下别人抓包看不到内容。
- 第一次给某台电脑传东西时，会自动记住它的「身份证」（证书指纹）。以后它换了系统重装过，会提示你指纹变了，按提示执行 `xlan pin forget 主机地址` 重新信任即可。
- 如果对方用的是旧版本，可能连不上，用 `xlan config set tls off` 临时退回不加密。
- **别人能看见你在网里**，但给你发文件必须经过你同意（除非你主动加了信任）。
- **不用特意关它。** 跑完命令它就退出了，后台那个服务下次用到会自动起来。
- **别删 xlan 所在的那个文件夹。** 配置和收件记录都存在它旁边，删了就得重新配置。
- 传文件的时候能看到实时进度：百分几、传了多少、跑多快。

## 一页纸速查

```
xlan autostart on|off|status       开机自启
xlan path on|off|status            加进 PATH
xlan serve                         前台启动服务
xlan serve -d                      后台启动服务
xlan serve --auto-accept           自动接收所有文件
xlan autostart on --auto-accept    开机自启并自动接收
xlan stop                          停掉服务
xlan sends                         看正在发的任务
xlan pause|resume <id>             暂停 / 继续
xlan log                           收发记录
xlan inbox clean --older-than 30d  清理旧记录
xlan scan                          看看谁在线
xlan send 文件 --to 名字            发文件
xlan send 文件夹 --to 名字          发整个文件夹
xlan text "内容"                    发文字给所有人
xlan text "内容" --to 名字          发文字给某个人
xlan inbox                         看收到的东西
xlan inbox accept [序号]           接收（只有一条时不用写序号）
xlan inbox accept --all            全部接收
xlan inbox reject [序号]           拒收
xlan inbox cancel [序号]           取消卡住的传输
xlan inbox cancel --all            取消全部未完成的
xlan trust add 名字                 以后这个人的东西直接收
xlan config set recv_dir 路径       换收件目录
xlan config set tls off            关闭加密（兼容旧版本）
xlan pin list                      看信任过哪些设备
xlan doctor                        出问题时自检
```
